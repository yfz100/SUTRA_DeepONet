# SUTRA-DeepONet

This repository provides the code used in our study of DeepONet surrogate modelling for coupled coastal groundwater flow and solute transport simulated with SUTRA.

The study considers transient groundwater responses under varying tidal amplitude and landward hydraulic head. A multi-output DeepONet is used to predict pressure head and solute concentration over space and time. The computational experiments are organized into three parts: supervised learning, physics-informed training, and transfer learning beyond the source forcing range.

## Repository Contents

The repository contains three independent code packages:

| Package | Description |
|---|---|
| `SUTRA_DeepONet_pure_v2_1.zip` | Pure supervised DeepONet for learning the mapping from hydraulic forcing conditions to transient pressure-head and concentration fields generated by SUTRA. |
| `SUTRA_DeepONet_physics_v2_1.zip` | Physics-regularized and physics-only DeepONet implementations using continuous governing-equation, initial-condition, and boundary-condition constraints. |
| `SUTRA_DeepONet_transfer_v2_1.zip` | Transfer-learning framework for adapting the pretrained supervised model to tidal amplitudes beyond the source forcing range using limited target-regime data. |

Each archive is self-contained and includes its own `README.md` with detailed instructions, model settings, configuration information, and execution procedures.

## Problem Setup

The DeepONet branch input consists of two hydraulic forcing variables:

\[
\mathbf{u}=[A,H_{\mathrm{land}}],
\]

where:

- \(A\) is the tidal amplitude;
- \(H_{\mathrm{land}}\) is the landward hydraulic head.

The model predicts two transient groundwater variables:

\[
[\psi(x,z,t),C(x,z,t)],
\]

where \(\psi\) denotes pressure head and \(C\) denotes solute concentration.

The reference solutions are generated using SUTRA for variably saturated, variable-density groundwater flow coupled with conservative solute transport.

## Experimental Framework

### 1. Pure Supervised DeepONet

`SUTRA_DeepONet_pure_v2_1.zip`

This package contains the supervised baseline model. The DeepONet is trained directly against SUTRA pressure-head and concentration fields.

The source dataset contains 168 complete SUTRA simulations generated from combinations of:

- 12 tidal amplitudes from 0.05 to 0.60 m;
- 14 landward hydraulic heads from 2.50 to 3.50 m.

The complete simulation cases are divided into 120 training cases, 24 validation cases, and 24 testing cases.

### 2. Physics-Informed DeepONet

`SUTRA_DeepONet_physics_v2_1.zip`

This package contains the physics-regularized and physics-only experiments.

Continuous strong-form residuals are constructed from the groundwater-flow and solute-transport equations together with the associated initial and boundary conditions. Adaptive weighting of physical loss groups is implemented using a group-level ReLoBRaLo strategy.

The physical residuals are continuous constraints evaluated through automatic differentiation. They are not the algebraic residuals of the finite-element and numerical time discretization used internally by SUTRA.

### 3. Transfer Learning

`SUTRA_DeepONet_transfer_v2_1.zip`

This package contains the transfer-learning experiments for prediction beyond the source tidal-amplitude range.

The pretrained supervised DeepONet is adapted using a limited number of SUTRA simulations from the higher-amplitude regime. One-shot and two-shot adaptation protocols are included, while most of the pretrained network remains frozen.

The transfer experiments evaluate whether limited information from the new forcing regime can improve prediction without retraining the complete model from scratch.

## Recommended Usage

Choose the code package according to the intended experiment:

- use `SUTRA_DeepONet_pure_v2_1.zip` for supervised training and baseline evaluation;
- use `SUTRA_DeepONet_physics_v2_1.zip` for physics-regularized or physics-only training;
- use `SUTRA_DeepONet_transfer_v2_1.zip` for adaptation to higher tidal amplitudes.

After downloading the required archive, extract it and refer to the `README.md` included inside the package for detailed instructions.

## Relationship Between the Three Packages

The three packages form a connected experimental workflow.

The pure supervised model provides the baseline DeepONet and the pretrained source model. The physics package uses the same underlying operator-learning problem to examine the influence of continuous physical constraints. The transfer package starts from the pretrained supervised model and evaluates adaptation beyond the source forcing range.

Together, they reproduce the main computational experiments reported in the associated study.

## Data

The code expects SUTRA-generated datasets following the data structures described in the README file of each package.

Because dataset and output paths depend on the local computing environment, users should update the corresponding configuration files before running the code.

Train, validation, and test partitions should be maintained at the complete simulation-case level to avoid information leakage between subsets.

## Software

The implementations are based on Python and PyTorch.

Additional package requirements and environment information are provided within the individual code archives.
